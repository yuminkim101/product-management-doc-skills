# 원페이저 점검표

항목별로 통과 / 보완 필요 / 해당 없음.

- [ ] 8개 섹션이 순서대로 있고 3분 안에 읽힌다
- [ ] 상단에 날짜·작성자·버전·상세 문서(링크 또는 "작성 전")가 있다
- [ ] 확인되지 않은 주장에 (가정), 모르는 값에 "미정"이 있다. 지어낸 수치가 없다
- [ ] 핵심 흐름이 한 줄로 시작 상황부터 사용자가 얻는 결과까지 이어진다
- [ ] 문제 → 가설 → 핵심 지표가 이어지고, 가드레일 지표가 있다
- [ ] 필수 범위가 3개 이내이거나, 넘는 이유가 있다. 제외 범위와 겹치지 않는다
- [ ] 확인 필요 사항마다 담당과 기한이 있다
- [ ] 피드백 요청 사항이 답할 수 있는 질문 2~3개다
- [ ] PRD가 있으면 결론이 PRD와 같고, PRD에 없는 내용을 더하지 않았다
- [ ] REQ 번호를 쓰지 않았다
- [ ] SKILL.md "문체" 규칙에 걸리는 표현이 없다
