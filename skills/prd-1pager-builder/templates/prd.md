# PRD 양식

- 장 순서와 번호를 바꾸지 않는다. 본문의 "18장 확인 사항 2" 같은 참조가 장 번호에 묶여 있기 때문이다.
- 쓸 내용이 없는 장은 지우지 않고 "확인 필요"로 남긴 뒤 18장에 질문으로 올린다.
- **(선택)** 표시가 있는 장·표는 작은 기능이면 "해당 없음" 한 줄로 끝낸다.
- 원페이저가 먼저 있으면 `templates/one-pager.md`의 대응표대로 이어받고 결론을 바꾸지 않는다.
- `>` 줄은 작성법이며 실제 문서에는 넣지 않는다.
