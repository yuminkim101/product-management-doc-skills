# 재입고 알림 신청 – 개발 요청서

## 한눈에 보기
- **무엇을**: 품절 상품에 "재입고 알림 신청" 버튼을 붙이고, 신청을 받을 수 있게 한다
- **왜**: 기획서에 명시되지 않음 (확인할 것 1)
- **구현할 기능**: 2개 (1. 재입고 알림 신청 2. 재입고 시 알림 발송)
- **플랫폼**: 확인 필요 (확인할 것 3)
- **일정**: 협의 필요 (확인할 것 4)
- **관련 디자인**: 재입고 알림 신청 버튼 디자인 요청서 v1.0 (시안 없음)
- **아직 정해지지 않은 것**: 16건 (디자인 요청서에서 이어받은 12건 + 개발 쪽 4건) → 맨 아래 "확인할 것" 참고

## 기능 1. 재입고 알림 신청 (REQ-01)

**사용자 관점 동작**
사용자가 품절 상품 옆 "재입고 알림 신청" 버튼을 누르면, 해당 상품의 재입고 알림 신청이 저장되고 완료 안내를 받는다.

**동작 규칙**
- 품절 상품에만 버튼을 노출한다
- 버튼을 노출할 화면 범위는 미정 (확인할 것 2)
- 비로그인 사용자 처리 방식은 미정 (확인할 것 5)
- 신청 단위가 상품인지 옵션인지 미정 (확인할 것 10)
- 신청 취소 가능 여부 미정 (확인할 것 6)

**필요한 데이터**
- 신청한 사용자, 신청한 상품(옵션 단위면 옵션 포함), 신청 일시
- 알림 수신 동의 여부 (알림 수단에 따라 필요 여부가 달라짐, 확인할 것 8)

**예외 처리**
- 같은 사용자가 같은 상품에 다시 신청하는 경우: 처리 방식 미정 (확인할 것 13)
- 신청 저장에 실패한 경우: 사용자 안내 방식 미정 (확인할 것 9)
- 신청 후 상품이 삭제되거나 판매 종료된 경우: 신청 건 처리 방식 미정 (확인할 것 14)

**완료 기준**
- [ ] 품절 상품에만 버튼이 노출되고, 판매 중인 상품에는 노출되지 않는다
- [ ] 버튼을 누르면 신청 정보(사용자, 상품, 신청 일시)가 저장된다
- [ ] 신청 완료 후 사용자에게 완료 안내가 표시된다 (안내 방식은 확인할 것 7 결정 후 확정)
- [ ] 중복 신청, 저장 실패 시 동작이 확인할 것 9·13에서 정한 대로 처리된다

## 기능 2. 재입고 시 알림 발송 (원본에 명시 없음)

> 기획서에는 "신청 버튼 생성"만 있고, 실제로 알림을 보내는 내용은 없습니다. 신청만 받고 알림이 가지 않으면 기능이 성립하지 않아 구현 대상으로 적었습니다. 이번 개발 범위에 포함할지 먼저 정해 주세요 (확인할 것 12).

**사용자 관점 동작**
신청한 상품이 다시 판매 가능 상태가 되면, 신청자에게 재입고 알림이 간다.

**동작 규칙**
- 알림 수단(앱 푸시, 알림톡, 문자 등) 미정 (확인할 것 8)
- 재입고 판단 기준(재고 0 → 1 이상, 판매 상태 변경 등) 미정 (확인할 것 15)
- 알림 발송 후 신청 건을 종료할지, 다음 재입고 때도 다시 보낼지 미정 (확인할 것 16)

**필요한 데이터**
- 기능 1의 신청 정보
- 알림 발송 결과(성공·실패, 발송 일시)

**예외 처리**
- 알림 발송 실패 시 재시도 여부 미정 (확인할 것 9)
- 수신 동의를 철회한 사용자에게는 발송하지 않아야 하는지 확인 필요 (확인할 것 8)

**완료 기준**
- [ ] 신청 상품이 재입고 기준을 충족하면 신청자에게 알림이 발송된다
- [ ] 발송 결과가 기록된다
- [ ] 발송 대상, 재발송 여부가 확인할 것 8·15·16에서 정한 대로 처리된다

## 비기능 요구사항
- 기획서에 없음
- 인기 상품은 신청자가 많아 재입고 시 한 번에 대량 발송될 수 있습니다. 발송 규모나 제한이 필요한지 확인할 것 15에 함께 묶었습니다.
- 신청 정보에 개인정보(사용자, 연락 수단)가 포함되므로 보관 기간 확인이 필요합니다 (확인할 것 8)

## 데이터 수집 (성과 측정)
- 기획서에 없음 (확인할 것 1과 함께 결정)
- 측정 후보: 버튼 노출, 버튼 클릭, 신청 완료, 알림 발송, 알림 클릭, 알림 후 구매 (어떤 걸 남길지는 확인 필요)

## 이번에 하지 않는 것
- 신청 내역을 모아 보는 화면 (확인할 것 12에서 포함 여부 결정)
- 관리자 화면에서 신청 현황을 보는 기능: 기획서에 없음
