# 원페이저 — 회원 탈퇴 만류 화면

2026-10-28 · 작성자 · v0.1 · 상세 문서: 회원 탈퇴 만류 화면 PRD v0.1

## 1. 요약
- **상황:** 회원 탈퇴를 선택하면 바로 탈퇴 절차로 넘어가고, 사라지는 혜택을 안내하는 단계가 없다. (가정)
- **문제:** 사용자가 잃게 되는 혜택을 모른 채 탈퇴할 수 있다. (가정)
- **근거:** 탈퇴 직전 보유 혜택 데이터는 아직 확인 전이다. (가정)
- **해결 방안:** 탈퇴 절차 앞에 잃게 되는 혜택을 한 화면에 보여 주는 만류 화면을 둔다.
- **핵심 흐름:** 탈퇴 메뉴 선택 → 잃게 되는 혜택 확인 → "탈퇴 계속" 또는 "회원 유지" 선택 → 탈퇴 절차로 이동하거나 이전 화면으로 복귀
- **비즈니스 효과:** 탈퇴 감소 (목표치 미정)

## 2. 가설
탈퇴 전에 잃게 되는 혜택을 한 화면에 보여 주면, 탈퇴하려던 사용자 중 일부가 회원을 유지할 것이다.

## 3. 핵심 지표
| 구분 | 지표 | 현재 → 목표 | 측정 방법·기간 |
|---|---|---|---|
| 핵심 | 만류 화면 회원 유지율 | 미정 → 미정 | "회원 유지" 선택 수 ÷ 만류 화면 노출 수. 출시 2주 후 기준선 설정 |
| 가드레일 | 탈퇴 관련 CS 문의·민원 수 | 미정 → 늘지 않음 | 출시 전후 4주 비교 |

## 4. 개발 범위
- **필수:** 만류 화면 노출, 잃게 되는 혜택 표시, 탈퇴 계속·회원 유지 선택
- **출시 직후:** 없음
- **핵심 정책:** 탈퇴 의사 재확인은 한 번만 한다. 혜택은 한 화면에 모두 보여 준다. "탈퇴 계속" 버튼은 "회원 유지"와 같이 눈에 띄게 둔다.

## 5. 제외 범위
- 기존 탈퇴 절차(본인 확인, 탈퇴 완료) 변경
- 탈퇴 후 재가입 안내

## 6. 일정
법무 검토 → 전체 출시 → 출시 후 리뷰. 날짜는 개발 범위 확정 후 기입.
