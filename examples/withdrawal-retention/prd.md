## 1. 요약

- **상황:** 회원 탈퇴를 선택한 사용자는 바로 탈퇴 절차로 넘어간다. 탈퇴 시 사라지는 혜택을 안내하는 단계가 없다. (가정, 18장 확인 사항 1)
- **문제:** 사용자가 잃게 되는 혜택을 모른 채 탈퇴할 수 있다. (가정)
- **해결 방안:** 탈퇴 절차 앞에 잃게 되는 혜택을 한 화면에 보여 주는 만류 화면을 둔다.
- **사용자 가치:** 탈퇴 전에 남은 혜택을 한 번에 확인하고 결정할 수 있다.
- **비즈니스 효과:** 탈퇴 감소 (목표치 확인 필요)
- **이번 버전 범위:** 만류 화면 노출, 잃게 되는 혜택 표시, 탈퇴 계속·회원 유지 선택

## 2. 배경

공정위는 2025년 10월 다크패턴 지침에서 탈퇴 의사 재확인을 2단계 이상 반복하는 것, 잃게 되는 혜택을 여러 단계로 나눠 알리는 것을 금지 대상으로 제시했다. 개인정보보호위원회는 2025년 12월 탈퇴 절차가 가입보다 어려우면 개인정보보호법 제38조 제4항 위반 소지가 있다고 보고 한 기업에 개선을 촉구했다. 만류 화면은 이 기준 안에서 설계해야 한다.

**벤치마킹 (선택)**

| 대상 | 방식 | 특징 | 반영할 점 |
|---|---|---|---|
| 확인 필요 | 확인 필요 | 확인 필요 | 국내 이커머스 앱 탈퇴 화면 직접 확인 후 추가 |

## 3. 주요 사용자

이 사용자의 불편을 먼저 해결하는 이유: 탈퇴를 선택한 사용자는 이탈 직전 단계에 있다. 남은 혜택을 모르고 탈퇴하는 경우라면 안내만으로 결정이 바뀔 수 있다. (가정, 18장 확인 사항 2)

| 구분 | 누구 | 기대하는 점 |
|---|---|---|
| 주 사용자 | 탈퇴 메뉴를 선택한 회원 | 탈퇴 전 잃게 되는 혜택을 한 번에 확인 |
| 부 사용자 | 확인 필요 | 확인 필요 |
| 내부 사용자 | 확인 필요 (CRM·마케팅 담당 등) | 탈퇴 사유 파악 (18장 확인 사항 5) |
| 기기 | 확인 필요 (18장 확인 사항 3) | |

## 4. 문제

**문제 정의:** 사용자가 잃게 되는 혜택을 확인하지 못한 채 탈퇴할 수 있다.

**근거**

| 근거 | 내용 |
|---|---|
| 탈퇴 데이터 | 확인 필요. 탈퇴 직전 보유 혜택(포인트·쿠폰) 분포 분석 필요 (18장 확인 사항 2) |
| 고객 의견 | 확인 필요 |

**현재 대안과 한계**

| 현재 대안 | 한계 |
|---|---|
| 탈퇴 전에 마이페이지에서 포인트·쿠폰을 직접 찾아본다 (가정) | 여러 메뉴를 따로 확인해야 해서 대부분 확인하지 않고 탈퇴한다 (가정) |

## 5. 문제 원인 분석

핵심 원인은 확인 필요. 아래는 가정이다.

| 번호 | 원인 | 설명 | 이번 버전 대응 |
|---|---|---|---|
| 원인 1 | 혜택 안내 부재 | 탈퇴 절차에 남은 혜택을 보여 주는 단계가 없다. (가정, 18장 확인 사항 1) | 해결 (REQ-01~02) |
| 원인 2 | 탈퇴 사유 미파악 | 사용자가 왜 탈퇴하는지 알 수 없어 개선점을 찾기 어렵다. (가정) | 확인 필요 (REQ-04, 18장 확인 사항 5) |

## 6. 가설

**가설:** 탈퇴 전에 잃게 되는 혜택을 한 화면에 보여 주면, 탈퇴하려던 사용자 중 일부가 회원을 유지할 것이다.

| 항목 | 내용 |
|---|---|
| 근거 | 5장 원인 1 |
| 검증 방법 | 만류 화면 회원 유지율 (15장) |
| 맞다고 판단하는 기준 | 확인 필요 (베타 후 기준선 설정) |
| 틀렸다고 판단하는 기준 | 회원 유지율이 거의 없으면, 혜택이 아닌 다른 이유로 탈퇴한다고 본다 |

## 7. 목표

1. 혜택을 모르고 하는 탈퇴 감소
2. 탈퇴 절차의 법 기준 준수 (재확인 반복 없음, 가입보다 어렵지 않음)
3. 탈퇴 사유 파악 (18장 확인 사항 5 결정 후)

## 8. 핵심 사용자 여정 (선택)

| 단계 | 고객 행동 | 고객 니즈 | 현재 불편 |
|---|---|---|---|
| 1. 탈퇴 결심 | 설정·마이페이지에서 탈퇴 메뉴를 찾는다 | 쉽게 찾고 싶다 | 확인 필요 |
| 2. 탈퇴 진행 | 본인 확인 등 탈퇴 절차를 밟는다 | 빨리 끝내고 싶다 | 확인 필요 (18장 확인 사항 1) |
| 3. 탈퇴 완료 | 탈퇴 완료 안내를 본다 | 정상 처리됐는지 알고 싶다 | 남은 혜택이 사라진 것을 뒤늦게 알 수 있다 (가정) |

이번 기능은 1단계와 2단계 사이에서 3단계의 불편을 미리 알린다.

## 9. 해결 방안

| 방법 | 판단 | 이유 | 재검토 시점 |
|---|---|---|---|
| 잃게 되는 혜택을 한 화면에 안내 | 채택 | 원인 1을 직접 해결. 한 화면이라 혜택 분할 안내 금지 기준에 맞춤 | 해당 없음 |
| 여러 단계로 나눠 재확인 | 제외 | 재확인 2단계 이상 반복 금지 대상 | 해당 없음 |
| 탈퇴 대신 휴면 전환 제안 | 보류 | 탈퇴 선택지가 가려지면 안 되며, 휴면 기능 자체가 별도 개발 | 확인 필요 (18장 확인 사항 4) |

## 10. 기능 요구사항

| 원칙 1 | 탈퇴 의사 재확인은 한 번의 탈퇴 시도 안에서 한 번만 한다. |

| 원칙 4 | 만류 화면의 오류가 탈퇴를 막지 않는다. 처리 방식은 법무와 확정 (18장 확인 사항 6) |
